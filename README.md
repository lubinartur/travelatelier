# Передача документации Travel Atelier

Скопируйте `docs/`, `CLAUDE.md` и `AGENTS.md` в корень репозитория с кодом прототипа. Если в репозитории уже есть файлы с этими именами, сравните и объедините правила, не стирая инструкции проекта. `docs/README.md` объясняет статус документов; `docs/CODE_AUDIT.md` перечисляет разрывы прототипа. Архив содержит документацию, не исходный код сайта.

Приоритет работы: сначала сохранить экспорт как исходную точку, затем исправить достоверность формы и контента, доступность/производительность движения, локализацию и маршруты. Не считать черновые коммерческие и юридические сведения утверждёнными.
