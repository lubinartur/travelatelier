# Travel Atelier — документация нового сайта

Рабочий комплект для проектирования и разработки сайта Travel Atelier OÜ. Основан на просмотре [действующего сайта](https://travelatelier.lovable.app/) 17.09.2026: главная (ET/RU), `/terms`, `/privacy`, `/terms-conditions` и пользовательский сценарий CTA. Это **бриф и спецификация**, а не утверждённые компанией тексты, условия страхования или юридические документы.

Визуальные и интерактивные решения главной синхронизированы с экспортом прототипа Google AI Studio от 17.09.2026. Для реализации главной читать `03-experience/DESIGN_DIRECTION.md`, `DESIGN_SYSTEM.md`, `HOMEPAGE_SPEC.md`, `COMPONENTS.md`, `UX_PRINCIPLES.md` и `MOTION_SYSTEM.md` как source of truth для дизайна и поведения. Прототип остаётся исходным примером, а не источником подтверждённых бизнес-фактов или готовой отправки заявки.

## Структура

| Папка | Назначение |
| --- | --- |
| `01-discovery/` | Факты, исходный контент, допущения и решения владельца |
| `02-strategy/` | Структура, контент, SEO и коммерческая логика |
| `03-experience/` | Страницы, UX, дизайн и компоненты |
| `04-delivery/` | Технические, аналитические и качественные требования |
| `../CLAUDE.md`, `../AGENTS.md` | Правила для кодовых агентов в корне репозитория |

Краткая сверка экспортированного кода и оставшиеся задачи: `CODE_AUDIT.md`.

## Порядок работы

1. Согласовать вопросы в `01-discovery/PROJECT_BRIEF.md`, прежде всего цифры, лицензии/роль в страховке, ESTO, отзывы и обработку заявок.
2. Утвердить дерево страниц и языков в `02-strategy/SITEMAP.md`.
3. Создать контент по `02-strategy/CONTENT_STRATEGY.md`, затем реализовать шаблоны.
4. До запуска проверить юридические тексты, формы, аналитику, доступность и производительность.

Маркировка: **Факт сайта** — виден на текущем сайте; **Рекомендация** — проектное решение; **Проверить** — требуется подтверждение компании. Все даты, адреса, условия и внешние ссылки перепроверить непосредственно перед публикацией.
