# Производительность

## Целевые показатели — проектные

На реальных пользователях, p75 по мобильным: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1. Оценивать отдельно главную и шаблон направления; значения достижимости уточнить по инфраструктуре и фото.

## Основные меры

- Hero: адаптивные размеры, современные форматы, корректный preload только критичного изображения, без тяжёлого видео по умолчанию.
- Фото направлений: responsive `srcset`, lazy load ниже первого экрана, фиксированные пропорции во избежание сдвигов.
- Шрифты: лицензированные файлы, подмножества с кириллицей и эстонскими символами, ограниченное число начертаний, `font-display`.
- Код: минимальный клиентский JavaScript; не загружать весь список карточек и сторонние виджеты как одну тяжёлую интерактивную часть.
- Кэширование статических ресурсов и изображений; сжатие; CDN по необходимости.
- Аналитика и внешние скрипты только после принятого решения по consent и влиянию на скорость.

## Проверка

Лабораторные замеры на мобильном профиле в CI для ключевых шаблонов; реальные метрики после запуска. Зафиксировать базовые значения и бюджет страницы перед внедрением видеоконтента или сторонних сервисов. Не добиваться оценок ценой удаления нужного содержания.
