# SEO-план

## Текущее состояние

У главной title `Travel Atelier`, meta description `Lovable Generated Project`. 18 направлений представлены секциями одной страницы; самостоятельных страниц направлений не обнаружено. Проверка выполнена в браузере 17.09.2026.

## Поисковая архитектура

Отдельные индексируемые URL для главной, каталога, качественно наполненных направлений, страховки, компании и контактов на ET/RU. Для каждой пары: уникальный title/description, один H1, canonical на собственный URL, двусторонние `hreflang` (`et-EE`, `ru-EE` при подтверждении рынка), `x-default` по согласованному правилу. Языковые URL и редиректы выбрать до разработки.

## Семантика

Исследовать реальные поисковые формулировки в Эстонии отдельно для ET и RU; не строить страницы по буквальному переводу ключевых слов. Кластеры: персональный подбор путешествий/туров, туристическое агентство и география обслуживания, направления, туристическая страховка. Список запросов и приоритеты подтвердить данными Search Console/исследованием, если доступно.

## Контент и разметка

Страницы направлений должны отвечать на намерение выбора, содержать уникальные критерии подбора и понятный CTA. JSON-LD `TravelAgency`/`Organization`, `BreadcrumbList`, при уместности `FAQPage` только для видимого контента и по действующим требованиям поисковых систем. Не указывать неподтверждённые рейтинги или отзывы в структурированных данных.

## Технический чек-лист

SSR/SSG или надёжно рендеримый HTML; sitemap с каноническими URL; robots; корректные 200/301/404; доступные ссылки вместо JS-only навигации; индексируемые ET/RU тексты; Open Graph; оптимизированные изображения; отсутствие дублированных страниц. После запуска проверить индексацию и ошибки в Search Console. Старый сломанный `/terms-conditions` не переносить как рабочую ссылку без реального документа.
