# Контент-стратегия

## Принцип

Продавать экспертный подбор через полезную конкретику: как агентство выясняет запрос, что сравнивает, кто отвечает за пакет и что происходит после обращения. Визуальное вдохновение поддерживает решение, но не заменяет информацию.

## Контентные направления

1. **Подбор:** критерии путешествия, процесс, что получает клиент.
2. **Направления:** кому подходит место, форматы отдыха, вопросы для выбора, актуальные ограничения только со ссылкой и датой проверки.
3. **Доверие:** подтверждённые отзывы, реальные кейсы с согласиями, команда/экспертиза, партнёры.
4. **Практика:** страхование, оплата, документы и контакты с ответственным источником.

## Модель записи направления

`id`, `slug`, `locale`, `name`, `intro`, `who_it_suits`, `trip_formats`, `selection_questions`, `hero_image`, `image_rights`, `cta`, `faq`, `last_reviewed`, `review_owner`, `status`. Не заполнять сезонность, цены, визы и режим въезда без проверенного источника и даты.

## Редакционный процесс

Черновик → фактчек компании/оператора → проверка ET/RU → юридическая проверка регулируемых утверждений → публикация → плановый пересмотр. Для юридических, платёжных и въездных данных устанавливать владельца обновлений. Устаревшую информацию снимать с публикации или явно маркировать.

## Контент на запуск

Для P0 нужны финальный текст главной, процесс, описание услуги, контакты, согласованные юридические документы и ответы на вопросы формы. Для P1 — не менее одного содержательного материала на каждое публикуемое направление, подтверждённые отзывы и условия ESTO. Изображения брать из лицензированных источников; вести реестр прав и согласий.
