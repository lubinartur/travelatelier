# Краткий audit экспорта Google AI Studio

Проверено 17.09.2026 по архиву `travel-atelier.zip` из исходной беседы. Архив распакован отдельно для чтения; исходные файлы под `sources/` не менялись. Статус ниже обновлён по текущему коду в репозитории.

## Структура и стек

Vite + React 19 + TypeScript + Tailwind CSS 4; `motion/react` для hero, `lucide-react` для иконок. Одностраничное приложение `src/App.tsx`, секции в `src/components/`, локализация ET/RU/EN в `src/data/translations.ts`, направления в `src/data/destinations.ts`. Фото грузятся с внешних Unsplash URL. Есть `@google/genai`, Express и dotenv в зависимостях, но в просмотренном UI нет подтверждённого серверного сценария.

## Что сохранить

Композицию центрированного hero и языковые переносы H1; шесть слайдов hero с таймером на 7 секунд, ручным выбором и прогрессом; однострочный header с dropdown; крупную горизонтальную ленту; четыре шага процесса с ручным выбором; чередование светлых и тёмных редакционных секций; общий принцип reduced motion. Текущий порядок секций описан в `03-experience/HOMEPAGE_SPEC.md`.

## Выполнено после переноса

1. **Форма заявки.** `TripPlannerModal` больше не показывает ложный успех: `handleSubmit` не вызывает `setIsSubmitted(true)`. Диалог с `role="dialog"`, focus trap/restore и закрытием через `useDialog`. Форма собирает обязательные поля (взрослые, дети, возраст каждого ребёнка, даты и продолжительность раздельно, контакты) и кнопкой открывает письмо на `info@travelatelier.ee` в почтовой программе посетителя (`mailto`); сайт ничего не отправляет сам и не показывает «успех». Серверная доставка — при появлении канала (CRM/почтовый сервис).
2. **Hero.** Шесть слайдов. Пауза при клавиатурном фокусе, скрытой вкладке и вне viewport; hover не останавливает. Ручной выбор начинает новый интервал 7 с. Видимая метка паузы локализована ET/RU/EN. `prefers-reduced-motion` выключает автосмену.
3. **Лента направлений.** `CuratedDestinations` останавливает RAF вне viewport и на скрытой вкладке; дубли карточек скрыты от фокуса и screen reader (`aria-hidden` / `tabIndex`), клавиатурный обзор есть.
4. **Why.** Интерактивные пункты — кнопки, а не clickable `div`.
5. **DestinationModal.** Семантика диалога, focus trap/restore и устойчивое закрытие через `useDialog`.
6. **Коммерческие утверждения на главной.** Нет IATA/bonds, лицензированных страховщиков, официального партнёрства ESTO и гарантированного покрытия. Why описывает подход без лицензий и «проверенных» отелей. Страховка и ESTO — осторожные формулировки; вопрос об услуге — `mailto:info@travelatelier.ee`. Действующие туроператоры названы в `Partners.tsx`. Реквизиты компании — в `Footer.tsx` и на `/terms` / `/privacy`. Вымышленные регистрационные/контактные данные из прототипа не публикуются.

## Открытые пункты

1. Проверить права на фото (Unsplash) и логотипы партнёров. `index.html` теперь `lang="et"` с локализованным `description` (язык и описание меняются вместе с языком интерфейса); отдельные языковые URL и `hreflang` — при переходе на маршруты по языкам. Неиспользуемые зависимости удалены.
2. Ссылки на условия Premio перепроверять при смене редакции (сейчас действует редакция с 26.01.2026).
3. **Отложено владельцем:** расхождение списка партнёров на `#partners` (Novatours, Tez Tour, Join UP Baltic, ANEX Tour, Interlux Travel) с блоком справочных ссылок операторов на `/terms` (включая заголовок Coral Travel / Anex Tour). Состав партнёров и оговорку о партнёрстве пока не менять. Битая ссылка `coraltravel.ee/reisitingimused` снята; стабильная официальная HTML-страница условий Coral не подтверждена.

## Расхождения со старыми документами

Старые спецификации описывали три шага, сетку карточек и запрещали автокарусель ключевого контента. Экспорт содержит четыре шага, горизонтальную ленту и hero slideshow. Структура страницы и порядок секций тоже отличаются. Новые документы фиксируют выбранный дизайн и условия управления движением, сохраняя прежнее правило о проверке бизнес-фактов.
