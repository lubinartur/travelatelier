# UX-принципы

1. **Естественная прокрутка.** Секции следуют без scroll hijacking и переключения контента от положения страницы.
2. **Контроль у посетителя.** Hero имеет видимый прогресс, ручной выбор и паузу; ручная смена сбрасывает таймер.
3. **Лента для обзора.** Направления медленно движутся, останавливаются при взаимодействии, доступны drag/swipe и клавиатурой. Название и действие понятны без инструкции «перетащите».
4. **Процесс выбирают вручную.** Все четыре пункта видны; первый выбран по умолчанию. Scroll не запускает их последовательно. Смена фото не сдвигает страницу.
5. **Один ясный следующий шаг.** CTA соответствует намерению; выбранное направление сохраняется в запросе.
6. **Доверие через проверяемость.** Партнёры, регистрация, страховка, ESTO, контакты и отзывы публикуются после проверки. Декоративные счётчики не заменяют факты.
7. **Заявка без ложного успеха.** Запрашивать минимум данных; успех показывать после ответа сервера, сохранять ввод при ошибке и давать резервный контакт.
8. **Полная локализация.** ET/RU/EN во всех текстах, состояниях и metadata. Dropdown экономит место; переносы крупных заголовков можно задавать по языку.
9. **Доступность движения.** При reduced motion нет автопереключения и автодрейфа; содержание и ручное управление остаются.

Проверочные задачи: найти направление и детали; перейти к запросу с контекстом; прочитать четыре этапа без самопереключения; остановить движение; переключить язык; найти условия и контакты; отправить запрос клавиатурой с достоверным результатом.
