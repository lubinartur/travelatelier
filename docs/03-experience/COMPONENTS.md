# Компоненты Travel Atelier

Названия ниже описывают роли; текущие имена экспорта указаны в скобках. Прототип не следует переносить без проверки.

| Роль | Экспорт | Контракт |
| --- | --- | --- |
| `SiteHeader` | `Header` | Один ряд на desktop: прозрачный внутри рамки hero на самом верху; после ~80 px — компактный светлый у верхнего края окна. На юридических страницах сразу компактный. Мобильное меню и CTA. |
| `LanguageDropdown` | `LanguageDropdown` | ET/RU/EN, текущий язык, Escape, клик вне меню, клавиатура и видимый фокус. |
| `HeroSlideshow` | `Hero` | Шесть фото, центрированный H1, 6–8 с на слайд (сейчас 7), crossfade, реальный прогресс, ручной выбор начинает новый интервал, пауза без hover, reduced motion. |
| `BrandStatement` | `BrandStatement` | Короткая типографическая секция с фото. |
| `DestinationRail` | `CuratedDestinations` | Большие фото, slow drift, drag/swipe, пауза при взаимодействии; дубли ленты не дублируют фокус и озвучивание. |
| `ProcessSelector` | `HowItWorks` | Четыре доступные кнопки, первый шаг активен, выбор только вручную, фото меняется без скачка высоты. |
| `EditorialBenefits` | `WhyTravelAtelier` | Тёмная секция с четырьмя пунктами подхода; интерактивные пункты — настоящие кнопки; без непроверенных лицензий и гарантий. |
| `Partners` | `Partners` | Пять подтверждённых туроператоров списком со ссылками на официальные сайты; без логотипов и реквизитов операторов. |
| `PracticalServices` | `PracticalServices` | Страхование и ESTO без непроверенных обещаний; вопрос об услуге — `mailto:info@travelatelier.ee`. |
| `TrustSection` | `TrustEcosystem` | Не на главной: логотипы, IATA и страховщики не подтверждены. Реквизиты компании — в футере и на юридических страницах. |
| `FinalCTA` | `FinalCTA` | Краткое действие на крупном изображении. |
| `EditorialImage`, `RevealOnScroll` | `EditorialMotion` | Повторно используемые фото/появления; alt, пропорция, фокус, reduced motion. |
| `SiteFooter` | `Footer` | Контакты, навигация и юридические ссылки после проверки. |

`DestinationModal` показывает черновые детали и ведёт к запросу с контекстом направления. `TripPlannerModal` содержит поля и локализованные состояния. `handleSubmit` формирует `mailto:info@travelatelier.ee` с заполненными полями и не показывает успех: доставку подтверждает только отправка письма посетителем. Поля дат и продолжительности разделены; возраст детей обязателен, если детей больше 0. Не передавать контакты в web-URL или аналитику (`mailto` открывает почтовую программу и в адресную строку сайта не попадает).

Общий критерий: семантический HTML, keyboard/touch, видимый focus, контраст, ET/RU/EN, 320–1440 px, отсутствие потери содержания при reduced motion.
